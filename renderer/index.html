Account

Sign in

Paste your AREDL API key to enable your profile, completed-levels view, submissions, and desktop notifications. The key is encrypted with your OS keychain and stored only on this machine — it is never sent anywhere except api.aredl.net.

App preferences

Theme

Pick a colour scheme. Glass and Adaptive Glass are see-through; Adaptive Glass also takes its colours from the level you're looking at.

Appearance

Accent colourReplaces the theme's highlight colour. (Adaptive Glass picks its own from the backdrop.)
Corner roundnessHow rounded cards and panels are.
List densityHow tall the rows in the Demon List are.
MotionTurns off page, menu and background animations.
PerformanceLite mode turns off blur, shadows and animations. Handy on older or slower computers.

Adaptive Glass

These only apply while the Adaptive Glass theme is selected.

Glass tintHow strongly the glass picks up the colour of the backdrop (0 = none). The accent colour isn't affected.
Colour methodGamma-corrected average blends the whole picture in linear light and tones it down. Most vivid picks the single punchiest colour.

Dates

Relative time decimal precisionHow precisely "x days ago" is written. 0 shows "3 days ago", 2 shows "3.25 days ago".

Background

Background blurHow blurred the level backdrop is. The mark on the slider is the default (60, or 54 on the Glass themes); Reset puts it back.
Background brightnessHow bright the backdrop is behind everything. The mark is the default (32, or 50 on the Glass themes).
Level pictureThe picture the backdrop and the profile banners use for each level. AREDL’s is the picture AREDL shows for the level; YouTube’s is a frame from its video. “My own file” puts one image, GIF or video behind everything. A single level can be switched by right-clicking it.
Backdrop fileNo file chosen. Images, GIFs and videos work; videos play silently on a loop. The shader still takes its colours from it.
Picture overwritesLevels set to a different picture than the one chosen above.
Backdrop styleImage is a blurred picture of the level you last looked at. Shader turns that picture’s colours into soft floating bubbles.
Shader speedHow fast the bubbles drift. At 0% they stand still, and the shader stops using any processing power. The mark is the default (100%).
Shader intensityHow strongly the colours show. Lower is a calmer, darker wash; higher is richer and more vivid. The mark is the default (100%).
BackdropThe level backdrop, in whichever style is chosen above.

Backup

Export & import

ExportPick what to take with you, then save it to a file or copy it as text. It works between Windows and Mac. Your account and API key are never included.
ImportLoad an export made by this app on any computer. You’ll see what is inside it and choose which parts to bring in. Settings that don’t exist on this computer are skipped and listed, and you can undo an import.

Sync & songs

Sync between computers

Google Drive folderSign in with a Google account, then create a new folder in its Drive or choose one that already exists. Each AREDL API key gets its own save file in the folder, so several accounts can share one folder. The app only reads and writes its own save file. The account and API key themselves are never synced.
Sync nowChoose between saving this app to the folder or using the folder’s save to overwrite this app. The copy that gets replaced is kept in the sync-backups folder first.
What to syncSettings that only exist on one system (like Windows’ window button colours) stay where they are.
Automatic timing
Save to Google DriveHow long the app waits between saving your changes to the folder. Nothing is sent when nothing has changed. The app also saves once when it closes.
Check for changesHow long the app waits between looking in the folder for changes made on another computer. Anything found waits for you to press Sync now.
Same time for bothSaving and checking use the save time above, in one request.

Unofficial desktop client for the All Rated Extreme Demons List. Not affiliated with aredl.net or RobTop Games. Level data, profile, notification and changelog endpoints are the public AREDL API — some endpoint paths were inferred and may need adjusting in main.js if AREDL changes their API shape.

Searching the list

Everything below can be mixed in one search box.

acheronAny level whose name, tags or description contains the text. "acheron"Quotes: the level's name must be exactly that (capitals ignored). Tags and descriptions aren't checked. 'ache'Single quotes: the level name must contain that text. Tags and descriptions aren't checked. acheron || bloodbath|| means "or" - levels matching any of the parts. id:61598653Level ID. Part of an ID works too. song:844658Song ID (from Newgrounds / the level info). tag:waveLevels with a tag containing the text. Use quotes for spaces: tag:"high cps" pos:50Exact placement. Also pos:1-75, pos:>150, pos:<=20 status:extendedmain, extended, legacy, pending or removed.

Putting them together

tag:wave pos:<=150Filters in one part must all match. tag:wave status:main || "fog"Each part around || is checked on its own, then combined with "or". sonic tag:2pFilters and plain text together: both have to match.

The tag button and the status / sort menus narrow the results further, on top of whatever you type.
